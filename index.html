tunnel — Helm repository

This is a Helm chart repository, not a website.

helm repo add tunnel https://scaffoldly.github.io/tunnel
helm install tunnel tunnel/tunnel --namespace tunnel-system --create-namespace

The same chart is published to the OCI registry at oci://ghcr.io/scaffoldly/charts/tunnel. This repo exists because listing available versions on a registry needs authentication and index.yaml here does not.
